# 💻 Gestion du Parc Informatique

Projet réalisé dans le cadre de mon stage, portant sur la **gestion et le suivi du parc informatique**.

## 📌 Description

Cette application permet de gérer les équipements informatiques d'une organisation de manière simple et organisée.
Elle facilite l'enregistrement, la consultation, la modification et le suivi des équipements du parc informatique.

## 🎯 Objectifs

* Gérer les équipements informatiques
* Ajouter, modifier et supprimer des équipements
* Consulter la liste des équipements
* Faciliter le suivi du parc informatique
* Organiser les informations dans une base de données
* Afficher des statistiques sur le parc

## 🛠️ Technologies utilisées

* 🐍 **Python**
* 🌐 **HTML / CSS**
* 🗄️ **SQL**
* 💻 **C**
* 📊 **Base de données**

## 🚀 Installation et utilisation

### 1. Cloner le projet

```bash
git clone https://github.com/hibalili828-spec/Gestion-du-Parc-Informatique.git
```

### 2. Accéder au dossier

```bash
cd Gestion-du-Parc-Informatique
```

### 3. Installer les dépendances

Si nécessaire :

```bash
pip install flask
```

### 4. Lancer l'application

```bash
python app.py
```

Puis ouvrir l'adresse indiquée dans le terminal dans un navigateur.
